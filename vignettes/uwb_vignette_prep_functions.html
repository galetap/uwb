Data preparation with prep_* and mean_* functions

Introduction

The first step of every plotting workflow in the uwb package is data preparation. The prep_*() and mean_*() functions take a raw, respondent-level data frame and transform it into a plot-ready tibble. This tibble always has a standardised structure (a yvar with the value to be plotted, an xvar with the category, label columns, and so on), which the plot_*() functions know how to consume.

This vignette describes the full family of preparation functions:

  • prep_single(), prep_gr(), prep_gr2() — distributions of a categorical variable, optionally split by one or two grouping variables.
  • prep_mc(), prep_mc_gr() — distributions of multiple choice questions (binary indicators of whether the item was chosen).
  • prep_bat(), prep_bat_gr() — distributions of batteries of items that share the same response options.
  • mean_bat(), mean_bat_gr(), mean_bat_gr2() — mean scores of numeric items, optionally split by one or two grouping variables.

It also covers the three auxiliary helpers (generate_textlabs(), impute_labs(), polish_var()) that the functions above call internally.

All examples use the built-in example_data dataset and the built-in codebook (see the Getting started with uwb vignette for their structure).

The shape of a prepared tibble

Before going through each function, it helps to understand the columns that every preparation function produces. The exact set differs slightly between functions, but the most important ones are shared:

Column Meaning
yvar The numeric value to be plotted — a percentage for the prep_*() functions, a mean for the mean_*() functions
n The raw count behind each yvar (frequency tables only)
nsize The group size (the denominator of the percentage / number of valid answers)
xvar The category placed on the category axis (final, plot-ready factor)
zvar A secondary category used for stacking / grouping (grouped and battery functions)
name The original variable name; used to match labels from the codebook
labvar, labvar_single, pos, pos_single, cvar_text Text-label content and positions, added by generate_textlabs()
title, subtitle, caption, lab Plot labels, added by impute_labs() from the codebook

Because the output is just a tibble, you can always inspect it, add columns, or override labels with mutate() before piping it into a plot_*() function.

Multiple choice questions

Multiple choice items are stored as a set of 0/1 columns, one per option (1 = the option was chosen). The prep_mc*() functions summarise how often each option was chosen.

prep_mc() — overall multiple choice distribution

prep_mc() takes the columns of the multiple choice block in vars and reports, for each item, the share of respondents who selected the value given in chosen. With 0/1 coded items, chosen = 1 gives the percentage who chose each option.

Batteries of items

A battery is a block of items that share the same (usually ordered) response scale, e.g. a set of agree/neutral/disagree statements. The prep_bat*() functions report the distribution of the response options for every item.

Mean scores

When items are numeric (e.g. ratings on a 0–10 scale), it is often more informative to report a mean than a full distribution. The mean_*() functions compute item means and return them in the same plot-ready shape, with yvar holding the mean instead of a percentage.

The mean functions parse the item values with readr::parse_number(), treating the strings listed in na_lab (by default "NA" and "Bez odpovědi") as missing. This lets them work both with numeric columns and with labelled/character columns that contain non-numeric “no answer” categories.

mean_bat() — means of a battery

mean_bat() returns the mean (and sample size) of each numeric item in vars.

mean_bat(example_data, vars = c("num1", "num2", "num3", "num4", "num5"))

Arguments:

  • vars — the numeric item columns.
  • round_places — number of decimals used for the rounded label (labvar_full).
  • na_lab — character values to treat as missing when parsing numbers.

Auxiliary functions

The preparation functions share three internal helpers. They are exported, so they can also be used directly in custom workflows.

generate_textlabs() — text labels and positions

generate_textlabs() takes a data frame that already contains a yvar column and adds the columns used by geom_text() in the plot functions:

  • labvar_full — the rounded value.
  • labvar_single — a character label for single-series bar charts (values below 0.5 are shown as "<1").
  • labvar — a character label used by stacked / dodged charts (very small slices are set to NA so they are not drawn).
  • pos, pos_single — the vertical position of each label.
  • cvar, cvar_text — the colour of the label, chosen for contrast against the bar.

The round_places argument controls the number of decimals.

tibble(yvar = c(5, 42, 0.3, 88)) |>
  generate_textlabs()

impute_labs() — labels from the codebook

impute_labs() looks for a codebook object in the environment and joins its title, subtitle, caption, and lab columns onto the data by the name column. If no codebook is found, those columns are added as empty strings. Every prep_*() and mean_*() function calls it automatically, which is why prepared data already carries plot titles when a codebook is loaded.

tibble(name = c("num1", "num2")) |>
  impute_labs()
Joining with `by = join_by(name)`

polish_var() — wrap labels and append sample sizes

polish_var() turns a “raw” category column (var_origin, by default xvar_df) into the final, plot-ready factor (var_final, by default xvar). It:

  • converts the column to a factor while preserving the original order,
  • optionally wraps long labels onto several lines (wrap, with chrnum characters per line),
  • optionally appends the group size as n = ..., colour-coded by how reliable the size is (nsize).

The x_wrap / x_chrnum / x_nsize (and z_*) arguments seen throughout this vignette are passed straight to polish_var().

tibble(
  xvar_df = c("A very long faculty name that needs wrapping", "Short"),
  nsize = c(15, 320)
) |>
  polish_var(chrnum = 20)
